# Guides

Subsystem-specific instructions, kept close to the work rather than in `CLAUDE.md`.

A specialist should pay for specialist context only when they need it. `CLAUDE.md` stays
small; when a subsystem grows its own rules, they go here and `CLAUDE.md` gains one
routing-table row pointing at them.

**Route agents to an exact file.** Never tell an agent to "search the repository for the
documentation" — that is how a bounded task turns into thirty tool calls and a worse
answer.

No guides exist yet. The first will likely accompany Phase 2 (test resolution), where the
implementation rules are subtle enough to be worth stating once rather than rediscovering.
