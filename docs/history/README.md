# History

Narrative records that are worth keeping but do not belong in `CLAUDE.md`, an ADR, or an
Issue: post-mortems, migration notes, and accounts of why something was rebuilt.

Kept separate so that `CLAUDE.md` stays a contract rather than an archive. Closed Issues
and merged PRs already hold the detailed record; this is for the occasional narrative that
would otherwise be lost between them.

Empty at bootstrap.
